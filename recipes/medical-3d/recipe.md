# medical-3d · 3D 医学

用三维人体与器官讲清“它在哪里、是什么结构、怎样工作、出了什么问题”。一侧是可聚焦的 3D 模型，一侧是与医学关系匹配的图文讲解。重点不是旋转一个模型，而是用镜头把观众的视线带到正确器官。

## 先确定医学叙事

- 先写一句视觉命题：观众最后应该看懂什么位置、结构、功能或病理关系，再决定要建哪些人体部分。
- 常规 3–6 场：全身定位 → 器官聚焦 → 结构或功能拆解 → 病理/健康建议 → 回到全身总结。不要每一场都重复同一套“标题 + 三个卖点”。
- 一个场景只回答一个核心问题。心、气道、脑、肝、胃、肾等部位由内容决定，不把部位枚举当成故事。
- 低模用于科普，不用于手术规划、诊断或治疗建议。器官位置与比例必须以可靠解剖资料为依据，不允许为了镜头好看把器官移错位置。

## 人体与模型

- 人体与器官一律用 `TT.anatomy`（BodyParts3D 真实解剖模型，见 `references/anatomy.md`）：半透明人体外壳帮助定位，目标器官保留清晰实体颜色。**不要再用球体、圆柱拼人体**，也不要自己摆器官位置——相对位置就是解剖位置。
- 同一器官跨幕保持颜色与材质基准。剧情需要放大时可以单独展示，但要保留回到全身定位的可能。
- 器官不是独立漂浮的装饰：人体、目标器官、光照与镜头共同解释空间关系。
- 片尾或说明必须保留署名：`模型 BodyParts3D · CC BY 4.0`。

## 分屏与右侧内容

- 3D 图层固定在左侧一块**白色圆角卡片**里：约 `x 0.04W`、`width 0.50W`、`y 0.085H`、`height 0.83H`。卡片给模型一个明确的舞台边界，模型被裁在卡片内是预期的，不要让它直接悬在页面底色上。
- 右侧 `x ≥ 0.60W`、宽约 `0.345W` 用于讲解；可以按内容调整，不要让模型与文字互相挤压。
- 右侧不限制形式：器官位置标注、功能流程、结构拆解、对照表、短数据、病理示意、健康建议都可以。选择能解释当前关系的形式，不复制卡片外观。
- 标题只承担医学主题，不重复旁白全文。正文短句与图形优先，必要时用本地 Canvas 小图补充。
- 底部 `y ≥ 0.90H` 是公共字幕预留区，模型重点、正文和图表不要侵入。

## 镜头与动画

- 开场先让全身位置可辨，再用 `0.8–1.6s` 平滑推进到目标器官；不要在第一帧直接贴脸，也不要只让模型原地旋转。
- 机位由模型数据推算，不写死坐标。全身按身高，器官特写按目标包围盒；位置和注视点一起插值，避免只推近目标点导致视角扭动：

```js
const H0 = TT.anatomy.height;                       // 3.8
const C = TT.anatomy.center('heart');               // 相机注视点
const SPAN = Math.max(...TT.anatomy.bounds('heart').size);
const FROM = { pos: [H0 * 0.34, H0 * 0.54, H0 * 1.72], at: [0, H0 * 0.50, 0] };
const DIST = SPAN / 0.58 / 0.689;                   // fov 38：可见高度 ≈ 0.689 × 距离
const TO = { pos: [C[0] + DIST * 0.40, C[1] + DIST * 0.12, C[2] + DIST * 0.90], at: C };
// draw 内：
const k = TT.ease.inOutCubic(TT.clamp01((api.t - 0.5) / 1.8));
```

- 器官充满画幅的 55%–75% 就够；再近会丢失胸腔参照，观众反而不知道镜头在哪。
- 全部由当前 `api.t` 的绝对函数计算，不要累加或缓存上一帧的相机状态，否则 seek 和导出会不一致。
- 不要在 3D 场声明 `scene.camera`：2D 画布缩放不会作用到 Three 图层，推拉一律改 3D 相机。
- 推近时让与当前主题无关的部位淡出：皮肤外壳与脑用独立材质，在 `k` 到达 `0.30–0.75` 之间把透明度降到 0，避免半截身体卡在卡片边缘。
- 聚焦后至少保留 `1.2s` 稳定阅读时间，再进行局部拆解。末段不要继续无意义旋转或推进。
- 退出聚焦可回到全身，也可保持器官特写；由叙事决定，不强制每幕往返。

## Three setup 契约

`api.three()` 会创建持久图层，只能在 setup 阶段调用。场景必须以 `return (ctx, api) => {...}` 结束；编译器检测到 `api.three()` 时会按两段式生成：setup 跑一次，返回的函数才是逐帧绘制。

```js
const STAGE = { x: W * 0.04, y: H * 0.085, w: W * 0.505, h: H * 0.83, r: 30 };
const layer = api.three({
  rect: { x: STAGE.x, y: STAGE.y, width: STAGE.w, height: STAGE.h },
});
const T = api.THREE;
// 在这里只创建一次几何、材质、人体与灯光。
layer.camera.position.set(2.0, 2.40, 10.4);

return (ctx, api) => {
  // 卡片先画，再把 3D 图层裁进圆角里；图层本身保持透明。
  ctx.save();
  ctx.beginPath(); ctx.roundRect(STAGE.x, STAGE.y, STAGE.w, STAGE.h, STAGE.r); ctx.clip();
  layer.draw(ctx);
  ctx.restore();
  // 右侧讲解内容照常画在 ctx 上。
};
```

- `rect` 同时决定图层位置和相机宽高比，不要另外创建第二块 WebGL 画布。
- 不给 `api.three()` 传 `background`：3D 图层透明，底色由 Canvas 卡片提供，圆角与阴影才有位置可依。
- `api.THREE` 由编译器在检测到 `api.three()` 后注入，不需要 storyboard 写 `needs`。
- 3D 对象必须跨帧存在，禁止在每帧函数里重新创建图层、几何或材质。
- 纹理图片用 `scene.resources` 声明；CanvasTexture 用 `api.canvas()` 离屏创建。禁止 `document`、异步加载和帧间可变历史。

## 模型与材质

- 人体只有 `TT.anatomy` 一条来路：`body` 皮肤，`brain` / `heart` / `liver` / `stomach` / `kidneys` / `airways` 六个内部结构。几何自带缓存，`TT.anatomy.mesh(T, part, material)` 即可上屏。
- 外壳 `depthWrite: false` + `transparent`，透明度 `0.17`；皮肤与脑各用独立材质，聚焦时才能分别淡出。
- `airways` 是气管与支气管树，不是肺实质——BodyParts3D 没有肺叶表面。讲呼吸时用气道树讲通路，肺泡层面的交换交给二维示意图，不要说成"肺的完整外形"。
- 器官颜色归本配方：默认配色见下节。非目标器官在特写里压到 `0.40–0.55` 透明度当参照，不要一起抢视线。
- 不做骨骼、血管、神经级拆解：模型是整体网格，没有子结构锚点。需要指向某个位置时用 `bounds` / `center` 定位，不要假装模型里有那块结构。

## 视觉规范

- 页面底色冷白 `#F4F7FB`，3D 卡片纯白 `#FFFFFF` 加一层很轻的投影（`rgba(32,59,90,0.10)`，`shadowBlur 36`）；主文字 `#203B5A`，辅助文字 `#65758A`，强调色 `#5C7FC1`。
- 人体外壳淡蓝透明（`#A8D4EA`，opacity `0.17`）；心脏暖红 `#E86A78`、气道青蓝 `#63B9D1`、脑紫 `#B58BE0`、肝棕红 `#B86D66`、胃橙黄 `#E9A65F`、肾紫红 `#A66FA0`，具体可随统一视觉系统调整。
- 灯光用于看清结构，不做高反射金属、厚重阴影或炫光。目标器官可以通过颜色与局部光照强调，不要全屏闪烁。
- `RULES.safeMargin = 0.045`；标题与正文使用 `sans-900 / JiangChengYuanTi`，字重不要靠描边模拟。
- `captions.style: plain`、`band: false`，字幕用江城圆体；BGM 为柔和垫乐。
