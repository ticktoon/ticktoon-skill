# 水墨写意 · code 场写法契约

这份只写**物理规律**：纸、墨、笔锋、留白、印章各自的行为。画什么由 LLM 在 `scene.code` 里实时决定，本文件不给题材、不给图元库、不给枚举。

## 1 载体

- `blocks: ["scene.code"]`，舞台只用 `TT.board.wash(ctx, api, { bleed: true })`。宣纸的长纤维与四周淡墨晕由它一次给足，**不许再铺第二层底色**。
- 笔迹只走 `TT.pen.stroke` / `TT.pen.track`，`pen: 'inkbrush'`；文字走 `TT.text`；印章走 `TT.mark.seal`。
- 镜头用 `TT.geom` 做反像采样，但保持静态（`ZOOM.from === to`）：推镜会让 ink 并集框每帧微涨，画面读起来像持续落笔；观感看 12 格联系表与人审。

## 2 墨色与笔锋

- 浓淡来自三件事，不用色块：**分段换宽度**（起笔重、行笔提、收笔按）、**灰度分层**（浓 / 中 / 淡三级）、**叠笔**（同路径低透明度重复）。
- 主墨线一笔分三段推进，段与段之间留一两个采样点的接续，不要同时开三组新笔。
- 洇染沿主线下缘铺若干道平行短线，越远越淡、越短；线的位置是序号的固定函数，不用随机数。
- 皴擦只压在下三分之一，短斜线成组，疏密随序号变化；上方大片留白是这一视觉的主体，不是没画完。

## 3 留白与落款

- 画面上三分之一不落墨线；题款（`TT.text`）用小字号放在左上或右侧空处，不与主体墨线交叠。
- 印章用 `TT.mark.seal`，`size` 约 0.05–0.06，`alpha` 淡入；**落在空处，不压墨线**。它不支持渐进，别给它传 `progress`。
- 题款文字不照抄旁白：code 只写画与款，解说交给字幕。

## 4 节拍

- 长旁白拆 2–3 场，每场独立 `scene.code`，`api.t` 从 0 起。
- 呼吸用时间重映射，一行搞定，别逐个改 `at`：
  ```js
  const T = api.t;
  const t = T < 1.2 ? T : (T < 2.2 ? 1.2 : 1.2 + (T - 2.2) * 2.2);
  ```
  `t` 只喂笔迹进度与 mark 的 `alpha`；**淡入淡出与相机必须用真实 `T`**。
- 最后一笔要在倒数第二个采样点之前落完，末 12% 完全不落新笔。

## 5 禁止

- 题材枚举（`scene` 选项挑画哪一幅）、预设图形库、把整段旁白抄进 code。
- 规则几何图形或纯色色块代替墨线；同一帧两种纸；印章压主体。
- 墨迹或文字越出 `preimage` 可行矩形（`safeMargin` 由 RULES 给，默认 0.09）。
- `Math.random` / `Date.now` / 任何外部 API：`tt det` 必须两次一致。

## 6 参数速查

| 项 | 取值 |
|---|---|
| `RULES.stroke` | `[3, 12]`（细 / 粗两端） |
| `RULES.safeMargin` | `0.09` |
| 灰度三级 | 浓 `#2b2d2b` / 中 `#6b6e69` / 淡 `#a8aaa4` |
| 印色 | `#a34030` |
| 笔种 | `inkbrush` |
| 舞台 | `wash` + `bleed: true` |

换题材时只换曲线控制点、排线区间与题款文字，上面这些物理规律不动。
