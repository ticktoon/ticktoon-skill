# ink-painting · 水墨写意

浓淡墨线慢慢长出来，大片留白交给观众补完。整幅内容写在 `scene.code` 里；下面只给纸、墨、笔锋、留白的物理规律，画什么由 LLM 实时决定，不给题材、不给图元库、不给枚举。

## 内容怎么写

- `narration` 拆 2–3 场，每场独立 `scene.code`；`code` 只写画与题款，不照抄旁白。
- 题款文字不照抄旁白：code 只写画与款，解说交给字幕。
- 最后 12% 不落新笔；题款与印章落在空处，不压主体墨线。呼吸用笔画之间的空档，不要冻结 `t`。

## 画面怎么写

### 载体

- code 场只写 `scene.code`；舞台只用 `TT.board.wash(ctx, api, { bleed: true })`。宣纸的长纤维与四周淡墨晕由它一次给足，**不许再铺第二层底色**。
- 笔迹只走 `TT.pen.stroke` / `TT.pen.track`，`pen: 'inkbrush'`；文字走 `TT.text`；印章用 `TT.mark.box` 方框 + `TT.text` 题字拼出。
- 镜头用 `TT.geom` 做反像采样，但保持静态（`ZOOM.from === to`）：推镜会让 ink 并集框每帧微涨，画面读起来像持续落笔；观感看 12 格联系表与人审。
- `rules.pen: inkbrush`、`rules.board: wash` 为固定值，换笔换板就换 recipe。

### 墨色与笔锋

- 浓淡来自三件事，不用色块：**分段换宽度**（起笔重、行笔提、收笔按）、**灰度分层**（浓 / 中 / 淡三级）、**叠笔**（同路径低透明度重复）。
- 主墨线一笔分三段推进，段与段之间留一两个采样点的接续，不要同时开三组新笔。
- 洇染沿主线下缘铺若干道平行短线，越远越淡、越短；线的位置是序号的固定函数，不用随机数。它是纹理，只落墨、不跟笔。
- 皴擦只压在下三分之一，短斜线成组，疏密随序号变化；上方大片留白是这一视觉的主体，不是没画完。皴擦同样不跟笔，笔只在主墨线上走。

### 留白与落款

- 画面上三分之一不落墨线；题款（`TT.text`）放在左上或右侧空处，不与主体墨线交叠。标题题款 `76 × RULES.scale.title`（样片场景 `76px`），副标题 `42 × RULES.scale.note`（样片场景 `52px`）；手写体笔画细，副标题低于 `40px` 就会看不清，不要按白板的注释档去缩。
- 副标题用浓墨 `#2b2d2b`，不要用中灰；层次靠字号拉开，不靠把字变淡。
- 印章用 `TT.mark.box` 画约 56px 方框（`shape:'round'`、`radius:5`、`width:4.5`），再用 `TT.text` 题字；整体轻斜、`alpha` 淡入，**落在空处，不压墨线**。不要给方框传 `progress`，印章是“砸”上去的。
- 题款 / 标题用千图笔锋手写（`QianTuBiFengShouXie`）：起笔收笔有锋，和水墨同源；字幕用文源宋体 Bold（`WenYuanSerifSC-Bold`），长句在 37px 下比手写体稳。

### 节拍

- 长旁白拆 2–3 场，每场独立 `scene.code`，`api.t` 从 0 起。
- 呼吸直接放在笔画之间：把下一笔的 `stroke.at` / `prog` 的 `at` 拉开 `0.4–0.8s`，**不要**用会冻结进度的时间重映射（例如 `t = T < 1.2 ? T : ...`）。`t` 停住时，正在画的墨线与笔身会一起停在半空，看起来像笔卡死，比等它画完更糟。
- 笔只跟主墨线：主轴进带笔的 `TT.pen.track`；洇染、皴擦、振颤、飞溅这类纹理放进第二个数组，用 `penBody:false` 只落墨，`dur` 0.15–0.3s 短揭示。两遍 `track` 共享同一时间轴，几十根短线之间不会出现笔来回跳。参考 `ref-shots/` 四个范例的 `strokes` / `detailStrokes`。
- 最后一笔（带笔与只落墨的笔迹都算）要在场景结束前 `≥0.6s` 落完，末 12% 完全不落新笔。

## 禁止

- 题材枚举（`scene` 选项挑画哪一幅）、预设图形库、把整段旁白抄进 code。
- 规则几何图形或纯色色块代替墨线；同一帧两种纸；印章压主体。
- 墨迹或文字越出 `preimage` 可行矩形（`safeMargin` 由 RULES 给，默认 0.09）。
- `Math.random` / `Date.now` / 任何外部 API：`tt det` 必须两次一致。

## 参数速查

| 项 | 取值 |
|---|---|
| `RULES.stroke` | `[3, 12]`（细 / 粗两端） |
| `RULES.safeMargin` | `0.09` |
| `RULES.scale` | `title 1 / label 0.75 / note 1.25`（题款标题 76、副标题 52 场景 px） |
| 字体 | 题款 / 标题 / 正文都用 `QianTuBiFengShouXie`（千图笔锋手写），在本场 `resources` 声明 manifest 键；字幕字体直接写 `captions.font: "WenYuanSerifSC-Bold"`（宋体，长句可读） |
| 灰度三级 | 浓 `#2b2d2b` / 中 `#6b6e69` / 淡 `#a8aaa4` |
| 印色 | `#a34030` |
| 笔种 | `inkbrush` |
| 舞台 | `wash` + `bleed: true` |
| 字幕 | `plain`，`baseSize 46`、`lineHeight 1.22`、`top 0.78`、`size 0.8`；底带不抢墨线 |
| 音频 | `audio.mood: "cut"`，音量 0.1；`forbid` 见 `recipe.json` |

换题材时只换曲线控制点、排线区间与题款文字，上面这些物理规律不动。

## 示例

`ref-shots/` 里的《一滴墨》三场：墨滴落纸先洇开再收住 / 笔锋提起，剩下交给留白 / 最后一方印落在空处。
三场对应“落墨、提笔、收印”，总时长约 10 秒。写法见 `ref-shots/`；文件头格式见 `SKILL.md`，只复用物理规律，不要照抄题材。
