# news-broadcast · 突发新闻

竖屏 `1080×1920` 的固定突发新闻模板：径向蓝底、世界地图、120px 网格与十条种子流动线；白色文源宋体双行标题、红色「消息来源」徽标、按固定视觉重心排版并逐字打出的正文，以及可选的底部品牌。标题与正文的重点行可用行首 `*` 标成黄色。没有旁白，也没有字幕；声音只有实录键盘声与 BGM。

**这是固定视觉 recipe，不是排版编辑器。** 画面只有四个动态字段：

| 字段 | 说明 |
|---|---|
| `title` | 主标题，`\n` 至多两行，每行建议 ≤10 字；行首 `*` 标重点行 |
| `content` | 正文，`\n` 手动分行，**2–6 个可见行**、每行 ≤13 字；空行作段落间距；行首 `*` 标重点行 |
| `source` | 来源机构，模板自动加「消息来源：」；40px 文字在红底内垂直居中 |
| `brand` | 可选台标/账号，默认空字符串不展示 |

`scene.params` 只写上表四个字段；其他键由 schema 直接拒绝。

## 何时用

- 单幕突发速报，8–12 秒，只讲「发生了什么 + 影响 + 来源」。
- 需要固定版式、换稿不换视觉的竖屏信息卡。
- 信息是硬事实，不需要主持人、评论或现场画面。

## 何时不用

- 多条不相关要闻 → `footage-cut` 或 `flash-cut` 组织多镜头；需要时间线复盘同理。
- 需要评论立场、解释背景、专家引语 → `whiteboard-explainer`（解释）或 `blackboard-lesson`（推导）。
- 需要现场图/视频 → 该 recipe 是纯版面块，不承担媒体画面。
- 需要旁白或 TTS → 该 recipe 是静默新闻卡，改用其他有旁白的 recipe。

## 内容怎么写

```json
{
  "params": {
    "title": "深夜突发\\n*地下管廊甲烷泄漏",
    "content": "凌晨三点\\n北岸新区地下管廊\\n甲烷泄漏 两条辅路封闭\\n*居民疏散 无人员伤亡",
    "source": "云港市应急局"
  }
}
```

- `title` 与 `content` 只用 `\n` 分行，模板绝不自动折行；放不下时整体缩字号。
- `content` 必须写 **2–6 个可见行**，空行不计入行数但会占据一个行距；中间插一个或多个空行可把正文分成两段。少于 2 行或多于 6 行直接编译失败。
- **重点行**在行首写 `*`，该行整行变重点黄 `rgb(247,255,5)`；星号会被去掉，也不计入打字时间戳。正文确实需要行首字面星号时，不要使用这个标记。
- `source` 只写机构名，模板自动加「消息来源：」；不要自己重复前缀。
- `brand` 省略时底部不显示；需要时写账号/台标，例如 `"@每日读研"`。
- **不要写 `narration`**：该 recipe 是静默场，时长用 `duration` 显式给；跑 `--tts` 也不会合成旁白。

## 固定视觉与数值

- 画幅固定走骨架的 `1080×1920@30`；模板固定满幅。
- 背景由公共 kit `TT.newsBg` 绘制：径向渐变中心 `(0.5W, 0.15H)`，色标 `#0078F2 / #0048C2 / #002277 / #000F42`；世界地图 `assets/image/world-map.png` 以 `contain` 放进 `0.9W × 0.45H` 的居中框，透明度 0.3；网格 120px、`rgba(255,255,255,0.2)`；十条流动线由 seed 7 固定起点与参数，随场景时间持续流动。背景首帧即满亮，不随 0.42s 入场淡入；退场仍正常淡出。
- 标题：89px 文源宋体粗体、居中，行距 30，投影 `rgb(28,27,27)`、blur 15、offset 4,4，`scaleUp` 入场；白色，行首 `*` 的重点行改 `rgb(247,255,5)`。
- 正文：65px 文源宋体粗体、居中，行距 30、字距 5，同款投影；从 0.9s 起按固定 `cps=10` 逐字打出，光标宽 20，打完即隐藏。整段以设计稿 `y≈1040` 为固定视觉重心：行数少时顶边下移、离上方更远；行数多时顶边上移、离上方更近，主体重心不变。
- 来源：红底 `rgb(141,7,7)`、白字；右缘固定在 `x≈914`，徽标按 40px 字号向左扩宽，文字按真实墨迹包围盒上下居中。
- 品牌：底部居中、白色、80% 不透明度、逐字轻起；默认不画。
- 主题 `broadcast` 的 `font.display/body` 都是 `WenYuanSerifSC-Bold`（`WYST_BOLD.woff2`）；`font.brand` 是钉钉进步体。BGM 走 `audio.mood = tense`，即「紧张脉冲弦乐.mp3」，音量 0.6。
- `caption: none`（fixed）：画面正文就是唯一文字层，不再叠第二套字幕。
- `template.sfxTrack`：`keyboard-loop` 从首字符铺到末字符，`fadeOut 0.06`，不逐字触发。
- `safeMargin 0.055` 只用于版面检查。

## 骨架样例

虚构快讯：云港市北岸新区地下管廊凌晨甲烷泄漏，两条辅路封闭、居民疏散、无人员伤亡。标题两行，第二行与正文末行用行首 `*` 标成重点黄；正文四行逐字打出，来源「云港市应急局」，不显示品牌，全程无旁白。
