# 快闪卡点 · brief

## 什么时候用

三句以上，每句一个结论，用硬切和大字连打；或者品牌口号、产品卖点、活动预告这种需要“大字占满画面”的短片。时长通常 6–30 秒。

不适合：需要解释机制、需要铺陈因果、需要连续旁白的长片。那些走 `whiteboard-explainer` 或 `illustrated-story`。

## 一句话原则

**每一场只做一件事：让一个大字/大数字/大图占住画面，然后切走。** 不是“排版一段文字”，是“把一句话砸到屏幕上”。

- 一场一个主角；主角可以是字、图像填字、数字、拼贴墙、波形或产品图。
- 配角只做三件事：色块、图案场、微标签（`01 / 06`、`129 BPM`、`EVERY = 1 FOOTNOTE = 1/5`）。
- 不铺陈、不解释、不写长句；短句直接给结论。
- 不是每场都要文字；图像、数据、波形也可以单独成场。
- 字不描边。粗细只靠字体和 `mask` 的 `weight`，不要给字加黑边、白边或投影。

## 画面

- 默认调色板在 `TT.flash` 里：黑底、白字、灰、橙 `#FF4D00`、深蓝 `#12305C`。要品牌色就直接给 `color` / `colors` 传 hex，不必受五种色限制。色块和卡片靠圆角、留白分界，不要画蓝色 UI 描边。
- 每场开头自己铺底色（`ctx.fillStyle = '#...'; ctx.fillRect(0, 0, W, H);`）；`scene` 不再有 `bg` 字段，漏铺就是黑底。
- 主标题字号至少到画面高度的 1/5；满幅字可以到 0.8–1.6 倍画面宽。
- 一场里字号必须拉开：主字 > 微标签 > 注释，不能出现两种相近字号。
- 允许全幅出血：字可以顶到 2.5% 安全边距，不要为了“稳”把字缩成字幕。
- 图像填字（`TT.flash.mask`）是重手法，不是默认手法：全片不超过 1/4 场，且不要连续两场都用。字就是窗口，默认无描边、无阴影、最多一层图片。不要给 mask 叠 `layers` 偏移层，也不要默认棋盘填充；图像填字场保持纯色底，不要上下再压棋盘条。窗口里的图默认静止，要横移/推近就传 `drift: [px/秒, py/秒]`，负值向左/上。
- 图像填字的底色不要拍脑袋写黑或白：先取帧，再用 `TT.flash.contrastColor(api, frame, { light, dark })` 按图内平均亮度选对比更强的一侧，微标签颜色跟着底色反选。底色和图内亮度接近时，字口边缘会糊成一片。
- 没有图就用棋盘、半调、斜条、色块（`TT.flash.pattern`），但它们是背景 / 图案场，不要塞进主字里冒充图片。
- 纯白底只用于“呼吸场”或数字刺点，不要整片白底；黑底也不是默认答案，按节奏换。

## 节奏

BGM 固定 `assets/bgm/fast-cut.mp3`（`audio.mood = cut`）：129.2 BPM，一拍 `0.4644s`，`beatOffset = 0.372s`。引擎不会自动把切点吸到拍上，**每场 `duration` 必须显式写成拍长的整数倍或半拍**：

| beats | duration |
|---|---|
| 0.5 | 0.2322 |
| 1 | 0.4644 |
| 1.5 | 0.6966 |
| 2 | 0.9288 |
| 3 | 1.3932 |
| 4 | 1.8576 |

- 单场最长 2.4s；超过就不是快切。
- 0.5 拍只做刺点：单字、数字、色块、闪白。
- 2–4 拍做完整画面：图像填字、拼贴墙、波形、数据卡。
- 一场里可以在中点做第二次动作（字换色、图换位、微标签跳数），不要一个画面从头停到尾。
- 跨镜承接：上一场色块铺满 → 下一场同色底 + 残留圆/缩小的暗块；或上一场大字冲出画面 → 下一场同字落在新位置。不要用叠化。

## 镜头写法

这些写法都在 `TT.flash` 里，具体参数见 `references/flash.md`；`demo.storyboard.json` 是可直接改的运行样例。

- 手法轮换：同一手法全片最多 2 次，且不连续。kit 只提供绘制词法，不会随机替你挑场景；每场用什么手法，由 storyboard 显式决定。

1. **逐字弹入**：`TT.flash.stagger`，每字 0.05–0.08s 延迟，`back` 回弹，字号占满宽度。
2. **图像填字**：`TT.flash.mask`，`fill:'image'`，`api.video/api.img` 取素材；字是窗口，不是字上贴图。
3. **拉伸字 + 速度线**：`TT.flash.stretch`，斜切 + 压扁 + 横向进场；速度线只做背景。
4. **棋盘 / 半调 / 斜条场**：`TT.flash.pattern`，给大字做底或做字内填充。
5. **数据卡 + 大数字**：`TT.flash.bars` 默认 `columns`，卡片底 + 左上标题 + 一排竖柱，最后一根橙色；不要画成两条横向进度条。大数字放在卡外或卡内留白处。
6. **波形刺点**：`TT.flash.wave`，黑底白条，中点换橙。
7. **三段式版面 + 双向文字**：`TT.flash.bands`，三条横带各带一句话，相邻带文字反向移动；`dir` 与 `speed` 逐带设置。
8. **双层文字视差**：`TT.flash.layers`，`lines[]` 两行字给不同的 `dx/dy`（每秒位移），远近感靠矢量差而不是模糊。
9. **四格卡片 / 拼贴墙**：`TT.flash.panels`，默认 `layout:'quad'`（左高图 + 右上两小卡 + 右下宽字卡），圆角、无描边；`collage` 只用于不等格拼贴。
10. **双向格子墙**：`TT.flash.panels`，`from:'alternate'` 让相邻格左右交替进场，或给单格 `from` / `offset`；图片、文字、色块可以混排。
11. **卡片墙焦点巡览**：`TT.flash.tour`，相机贴三张卡做三角移动，末尾拉远全景；正文用 `micro` 放镜头外。
12. **圆 / 格子 / 条形揭图**：`TT.flash.reveal`，用素材本身当主角。
13. **格子焦点 → 原图铺屏**：`TT.flash.gridFocus`，同镜从格子墙放大到完整原图，适合收尾。
14. **故障切片**：`TT.flash.glitch` 放最后切 1–2 帧；故障风大字用 `TT.flash.glitchType`，按 `t/dur` 在 1–2 个窗口爆发条带错位，窗口外保持干净字面，单字跳色，只切字不切背景。

## 素材

- 有品牌图/产品图/实拍就优先用；没有就纯字 + 图案 + 色块，不要硬找无关图。
- 实拍/视频素材场不超过全片 1/3；快闪的主体仍然是字。
- 4:1 长图/横幅用 `contain`，不要 `cover` 把字裁掉。
- 视频资源声明 `{ type: 'video', name, src }`，代码里 `api.video(name)`；图片用 `api.img(name)`。

## 交付前

- `tt build`、`tt stills`、`tt qa`、`tt det`。
- `qa` 的 `must` 必须为 0：现在只抓空墨迹、recipe 自带的 verify / forbid；排版是否安全靠 12 格联系表自己看。装饰层请走 `TT.flash.mask/layers` 的离屏合成，不要在主画布重复 `fillText`。
- `captions` 固定 `none`；画面文字就是正文，不要再叠字幕。
- 不导出 MP4，除非用户明确要求。
