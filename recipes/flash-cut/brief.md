# flash-cut · 快闪卡点

三到五个短句，硬切连打，不铺陈、只给结论。画面文字就是正文，配 `cut` 情绪 BGM。

## 何时用

- 情绪或观点需要连续重击：一句一场，单场 ≤2.4 秒。
- 文案本身有节奏，画面只需要一个字或一个短句占满视线。
- 不想写字幕、不想铺叙事，只要结论砸出来。

## 何时不用

- 需要解释因果、步骤或数据 → `whiteboard-explainer` / `crayon-guide`。
- 需要用真实镜头讲事实 → `footage-cut`。
- 句子超过 12 字或需要三行正文 → 拆成更多场，不要缩字。

## 内容怎么写

- `narration` 一句一场，每句 3–10 字；每场独立 `scene.code`，`api.t` 从 0 起。
- 一句只留一个视觉锚点：一个词、一条横线、一个数字或一块色域；不要在同一场叠两种标题。
- 场间默认硬切；需要呼吸时用一次 `dip-to-color`，同色 dip 全片只用一对。
- 字幕固定 `none`：不要再叠一条字幕把同一句话写两遍。

## 视觉与数值依据

- `style`：近黑底（`bg #0A0A0C`）、暖白字（`ink #F5F2EA`）、金色强调（`accent #D9A441`）。
- `rules.safeMargin: 0.05`；标题基准字号靠 `scale.title: 1.6` 拉大，标注 `0.7`、注释 `0.45`，三档必须一眼可辨。
- `rules.stroke: [2, 7]`：细线做分割，粗线做强调；不要出现中间档。
- `captions.style: "none"`；`audio.mood: "cut"`，音量 0.11，淡入 1s / 淡出 1.8s。
- `forbid`：单场超过 2.4s、同场两个相近字号、叠字幕、用同色 dip 连续假装叠化。

## demo

《潮水退了》五句：潮水退了 / 风从北边来 / 灯一盏盏灭了 / 只剩潮声 / 天亮了。
五场硬切，每场一个短句占满画面，末句收在亮起的底色上。
