# 快闪卡点 · code 场写法契约

只写**画面与时间的物理规律**：画幅、拍点、字号阶梯、素材窗口、硬切与收尾。每场写什么短句、用什么手法，由 `scene.code` 当场决定；本文件不给题材、不给句子模板。

## 1 画幅与底色

- 逻辑画幅 1920×1080，`safeMargin = RULES.safeMargin`（本 recipe `0.025`）；字可以出血到 2.5%，但不要再把主字缩回字幕尺寸。
- 每场开头自己铺满底色：`ctx.fillStyle = '#...'; ctx.fillRect(0, 0, W, H);`。场景没有 `bg` 字段，漏铺就是画布黑底。
- 底色只用黑 `#0A0A0A`、纯白 `#FFFFFF`、橙 `#FF4D00`、深蓝 `#12305C` 这一组，或品牌明确给出的 hex；不要用纸白、米白、奶油色。
- 一秒内的底色切换要成对：上一场铺满某色，下一场用同色底承接，再换主色。不要用叠化假装跨场。

## 2 拍点与场长

- BGM 固定 `assets/bgm/fast-cut.mp3`，`129.2 BPM`；一拍 `0.4644s`，`beatOffset = 0.372s`。
- 每场 `duration` 必须是半拍或整拍的倍数：`0.2322 / 0.4644 / 0.6966 / 0.9288 / 1.3932 / 1.8576`。
- 单场最长 `2.4s`；超过就不再是快切。0.5 拍只做刺点；2–4 拍做完整画面。
- 一场至少有一次动作变化：中点换色、换位、微标签跳数，或后半拍换构图。不要一个静止画面从头停到尾。

## 3 字号阶梯

- 主标题（字、数字、图像填字）至少 `0.2H`（1080p 约 216px）；满幅字可以到 `0.8–1.6W`。
- 同一场只允许三档：主字 > 微标签 > 注释。相邻两档不能接近；`RULES.scale` 的 `title 2 / label 0.72 / note 0.5` 只是起点，实际字号按画幅算。
- 字不加描边、不加投影、不加黑白边；粗细只来自字体和 `TT.flash.mask` 的 `weight`。
- 微标签只做配角：编号、BPM、单位、脚注式短词；不要用微标签承担主句。

## 4 素材窗口

- 实拍场不超过全片 `1/3`；快闪主体仍然是字、数字、色块或图案。
- 图像填字用 `TT.flash.mask`：字是窗口，不是字上贴图；全片不超过 `1/4` 场，且不连续两场使用。
- 填字场保持纯色底，窗口里的图默认静止；要移动就传 `drift: [px/秒, py/秒]`，不要自己算时间位移。
- 底色按图内平均亮度选：`TT.flash.contrastColor(api, frame, { light, dark })`；微标签颜色跟底色反选。
- 没有合适素材时用 `TT.flash.pattern` 做图案场，不要硬找无关图；图案只做背景或字内填充，不冒充主体。

## 5 揭示与切点

- 一场只做一件事：让一个字、一个数字、一张图或一组拼贴占住画面，然后切走。
- 硬切入；转场只能靠底色承接、同字位移或色块残留。禁止叠化、dip-to-color 连用。
- 同一手法全片最多 2 次，且不连续；手法轮换见 brief 的技法表，具体参数见 `references/flash.md`。
- 跨镜承接优先：上一场色块铺满 → 下一场同色底 + 残留暗块；或大字冲出画面 → 同字在新位置落定。

## 6 收尾

- 最后一场信息最少、字号最大；用故障、色块或单字收束，不再引入新元素。
- 最后一拍留给静止或一次单一切片；不要在片尾同时开新字、新图、新色块。
- `captions` 固定 `none`；画面文字就是正文，不再叠字幕。

## 7 禁止

- 一场多主角、多句并列、长句解释；快闪不铺陈因果。
- 两种相近字号同场；主字小于 `0.2H`；满屏只有一行居中文字而没有层次。
- 给文字描边、给卡片画蓝色 UI 边框、给图像填字叠阴影或棋盘填充。
- 用 `Math.random` / `Date.now` / 外部 IO；`tt det` 必须两次一致。
- 在同一场景写 `scene.params`；本 recipe 只收 `scene.code`。

## 8 参数速查

| 项 | 取值 |
|---|---|
| `RULES.safeMargin` | `0.025` |
| `RULES.scale` | `title 2 / label 0.72 / note 0.5` |
| 一拍 | `0.4644s`（半拍 `0.2322s`） |
| 单场上限 | `2.4s` |
| 底色 | `#0A0A0A` / `#FFFFFF` / `#FF4D00` / `#12305C` |
| 字幕 | `none` |
| 主体上限 | 实拍 ≤ `1/3` 场；图像填字 ≤ `1/4` 场且不连续 |
