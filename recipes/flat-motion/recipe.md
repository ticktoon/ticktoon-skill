# flat-motion · 扁平 MG

高饱和底色、圆角几何、清楚的大色块与有弹性的物体表演。接近万彩动画大师一类扁平 Motion Graphics：不是把静态插画缓慢放大，而是让人物、图标、道具和文字按戏剧节拍运动。

视觉与运动参考：[mg-styles-15 / Flat Vector](https://github.com/Vincentwei1021/mg-styles-15/tree/main/demos/01-flat-vector)。这里提炼色彩、几何和运动规律，不复制原演示的品牌、文案或完整故事。

选中本 recipe 后，以这份文档为创作纲要。`ref-shots/` 是独立镜头写法，不是剧情模板；正式故事仍在每场 `scene.code` 里重新组织。

## 内容怎么写

- 一场承担一个视觉命题：问题出现、角色发现、功能发生、结果完成、品牌收束。先找能被演出来的主体，再写旁白，不把抽象句子直接贴满画面。
- 常规短片写 3–6 场，每场约 4–8 秒。一个场内可以有 2–4 个动作拍点，但它们必须围绕同一个空间或同一个连续变形主体。
- `narration` 讲完整意思，画面只提炼 2–8 字关键词、数字或短标签。公共字幕固定 `karaoke`，使用江城圆体；**画面文字不得重复 narration 或替代字幕**。长句拆成多个 cue 或场，优先单行字幕，不让两行字幕向上侵入主体。
- 优先使用能被连续表演的关系：圆点 → 太阳 → 通知；柱状图 → 对勾；手机提醒 → 角色行动；道具 → 标题的一部分。转场只是场边预设，不能代替场内的因果动作。
- 若内容只有口号、没有人物/物体/图标的空间表演，改用 `flash-cut`。

## 画面怎么写

### 色板与几何

- 默认色板来自参考源码：群青 `#2B2BFF`、深群青 `#1F1FCC`、浅群青 `#4D4DFF`；珊瑚 `#FF5A4E`、珊瑚暗面 `#E0433A`；向日葵黄 `#FFC62B`、黄色暗面 `#F0A91A`；薄荷绿 `#2EE6A8`、绿色暗面 `#1FC28C`；奶油白 `#FFF6E9`、米灰 `#F1E3CC`；墨蓝 `#151433`。
- 同场使用 1 个主背景色、2–3 个主体色，再加奶油白和墨蓝。重点主体可跨场保持同一种颜色，让观众认出“还是它”。
- 医疗、政务、教育等服务讲解可使用暖橙辅助色板：纸底 `#F7F5F0`、标题橙 `#E9853C`、虚线深橙 `#C96432`、强调黄 `#F7B84B`、墨蓝 `#34304A`。橙色只用于标题和说明框，主体插画保持清楚的蓝绿/肤色层次；不在底部另加彩条。
- 用圆、圆角矩形、胶囊、半圆、三角形与粗圆头线构图。主体通常不描边；需要侧面时，在一侧增加占宽度约 12–16% 的同色暗面，不用写实渐变。
- 接触阴影用低饱和扁椭圆，不能用大面积模糊黑影。装饰可以是同底色深浅差、圆环、十字、短线和半圆，数量少于叙事主体。
- 背景可直接用 `ctx.fillStyle` + `fillRect` 满幅平涂，不调用纸、黑板或幕布 kit。文字与关键主体留在 `RULES.safeMargin` 内，装饰和背景可以出血。

### 构图与空间

- 先确定一个清楚的视觉锚点：落地 baseline、桌面、手机、角色髋部、图标中心或标题基线。所有变形都围绕这种语义锚点，而不是默认围绕画布中心。
- 建筑与道具从地面或支撑面生长；气泡从尾尖弹出；人物上臂绕肩、前臂绕肘；标题逐字围绕自己的基线回弹。
- 大场面采用远景低对比、主体高对比、前景少量遮挡三层。小场景只保留一个主动作，避免所有道具同时抢戏。
- 镜头推进只在一个视觉焦点上发生，整幅世界共用一组 `translate / scale`。不要给每个物体各算一套互相矛盾的相机。
- 服务讲解型构图可让固定讲师占左侧约 30–35%，右侧放 1–2 组功能插画；橙色标题管主题，虚线说明框管短卖点。讲师、插画与文字按这个顺序进入，不要所有信息同时出现。**底部 `y ≥ 955`（1080p）是 karaoke 字幕预留区，场景不得另画总结彩条、总结文字或说明框。**
- 双栏对比只比较两个维度，中间用一条虚线或留白分隔。两栏标题层级一致，插画大小相近，说明框数量可以不同，但底线和阅读方向必须稳定。

### 动作三阶段

每个主要动作按以下结构写，时间只是基准，不是逐帧关键帧堆叠：

1. **预备**：0.10–0.25 秒，反向压缩、下蹲、后退或缩小，幅度通常 5–20%。
2. **发生**：0.25–0.60 秒，用 `TT.ease.outCubic / outQuart / back` 完成位移、生长或变形。
3. **稳定**：0.15–0.40 秒回弹，随后停在可读的最终状态。末 12% 不再引入新主体。

```js
const p = (at, dur) => TT.clamp01((api.t - at) / dur);
const pop = (at, dur = 0.48) => Math.max(0, TT.ease.back(1.70158)(p(at, dur)));
const sy = Math.max(0.001, pop(0.4));
const sx = 1 + (1 - sy) * 0.22;
ctx.translate(cx, groundY);
ctx.scale(sx, sy); // 原点位于地面，不是建筑中心
```

- 挤压拉伸保持视觉体积：常用 `sx = 1 + k`、`sy = 1 / (1 + k)`，`|k|` 通常不超过 0.25；落地时横向变宽，飞行时沿速度方向拉长。
- 多物体入场 stagger 通常 0.06–0.16 秒，可从中心向两侧、从主到次或沿运动方向排列，不按数组机械同时弹出。
- 待机动画只用 1–4px 位移、1–2° 摆动或低幅呼吸。主动作发生时减少无关待机，让注意力只有一处。
- 所有动画是 `api.t` 的纯函数。需要随机位置时用固定 `api.seed` / 固定序号；禁止 `Math.random`、`Date.now`、异步绘制与帧间历史。

### 变形与连续主体

- 变形优先共享颜色、圆心、基线或接触点：圆点扩张成太阳、圆角柱变成标题一笔、气泡扩张成下一场底色。
- 形变不能只靠交叉淡化。至少让尺寸、轮廓、位置或 pivot 中的一项连续变化；颜色可以保持，让观看者追踪同一个主体。
- 圆形擦除、色块扩张和 match cut 在 `scene.code` 内完成。跨场仍只声明固定 `transition` 预设，优先 `zoom-pop` / `iris` / `morph`，未声明按硬切。

### 音效：只对关键动作，克制试点

`scene.sfx` 是场景内音效事件数组，`at` 使用与 `api.t` 相同的场景内秒数，必须与 `scene.code` 中动作开始或落稳的时间一致；`volume` 可省略，但试点建议显式压低。BGM 固定 `mood: soft`，只铺柔和垫乐，不使用卡点音乐。

```json
"sfx": [
  { "name": "common-swipe", "at": 0.55, "volume": 0.18 },
  { "name": "common-pop", "at": 1.8, "volume": 0.2 }
]
```

- 大幅变形或跨场过渡可用一次 `common-whoosh`（建议音量 `0.16`）；普通硬切、待机和微位移不配音。
- 分栏或多个面板构成一个整体滑入时，只在主动作开始用一次 `common-swipe`（`0.18`），不要左右栏各放一次。
- 主图标、核心功能点弹入可用一次 `common-pop`（`0.20`）；连续 stagger 不给每一项逐个配音。
- 每个镜头通常 `0–1` 声，确有两个清晰动作拍点时最多 `2` 声；不默认叠重低音、通知音或成功音。
- 音效不是装饰清单：画面没有对应动作就删掉事件，改变动作时间时同步修改 `at`。

### 人物、图标与文字

- 人物由圆头、圆角躯干、粗圆头四肢和少量五官组成。动作绕肩、肘、髋等关节；表情用眼睛缩放、眉毛和嘴形变化，不画写实细节。
- 图标要能一眼识别：柱状图、对勾、心形、钱币、通知、手机等都用几何基本形构成。图标不是静止徽章，要参与生长、书写、翻转或裂变。
- 标题常用 `TsangerShuYuan`、`ZTYueDongHei` 或 `sans-900`，正文/标签用 `JiangChengYuanTi`、`sans-700` / `sans-400`，均在本场 `resources` 声明。
- 标题逐字或按词回弹，字距和宽度由真实 `ctx.measureText` 计算；不要按字数猜总宽。标签字号约 `72 × RULES.scale.label`，注释约 `72 × RULES.scale.note`。
- 画面文字与 narration 不重复：narration 说“通知会及时提醒你”，画面可以只写“及时”并演出手机气泡。

## 禁止

- `scene.params`、固定题材/人物/图标枚举、所有场共用一张构图。
- 纸纹、照片、厚渐变、玻璃拟态、重阴影；静态插画只做缓慢 Ken Burns 缩放。
- 所有元素同时淡入、围绕中心无锚点缩放、持续高频抖动、满屏只有一行字。
- 公共字幕与画面大字重复；把整段旁白复制到场景文字。

## 参数速查

| 项 | 取值 |
|---|---|
| 模式 | `code`，每场独立 `scene.code` |
| 安全边距 | `RULES.safeMargin = 0.045`；文字与关键主体遵守 |
| 线宽 | `RULES.stroke = [4, 18]`，圆头线；主体优先色块而非描边 |
| 字号基准 | `72 × RULES.scale`：title 2 / label 0.85 / note 0.5 |
| 字幕 | `karaoke` + `JiangChengYuanTi` 40px；`at: bottom`、`top: 0.89`，高亮 `#FFC62B`；底部预留区不放场景文字/彩条 |
| 节拍 | 有旁白场 lead-in 0.35s / hold 0.8s / 最短 4s；常规场 4–8s |
| 音频 | `mood: soft`，音量 0.10，淡入 0.6s / 淡出 1.4s；关键动作可写少量 `scene.sfx` |
