# whiteboard-explainer · 白板手写

整幅白纸（或绿黑板）逐笔长出来，观众看着答案被画出来。视觉是主角，叙事由 storyboard 自由组织——
该 recipe 只规定「必须统一才不散」的部分：字体、笔、字号阶梯、线宽、安全边距、字幕样式与禁用组合；颜色由 code 直接写 hex 或走 kit 默认值。

选中本 recipe 后，内容怎么写、画面怎么画都以这一份文档为准。下面只写与内容无关的物理定律；换内容不改变这些关系。

## 内容怎么写

- `scene.code` 必须是本场唯一的内容载体，画面自己铺满画幅。
- 内容不要塞进 recipe 的枚举参数：讲解词写 `narration`，画面与标注全部写进 `scene.code`。
- 整幅场景内部已用 `TT.pen` 逐笔生长：纸底/板面 → 陆地与海洋剖面 → 太阳、云、雨 → 信风与暖水 → 注释箭头，至少 3 个视觉图层；最后几笔收束后停笔，镜头继续缓慢推进。
- 先纸面 / 板面，再主体轮廓，再标注文字。标注不得早于它指向的主体笔画；文字提前出现会让画面先有“结论”，后有“证据”。
- 标题可以是第一笔，但它是锚点，不是主体；主体轮廓仍要先于所有说明性标注。

## 画面怎么写

### 坐标系与安全区

- 逻辑画幅 1920×1080；安全边距 `m = RULES.safeMargin`（样片 `0.06`）。安全框为左右 6%、上下 8%，单一标量取全轴下界 0.06。
- 安全框像素：`x0 = W*m = 115.2`，`y0 = H*m = 64.8`，`x1 = 1804.8`，`y1 = 1015.2`。probe 显示为 `115 / 65`，不要手写这两个整数。
- zoom > 1 时，可见场景区域向 focus 收缩；内容必须放进 `TT.geom.preimage` 的可行矩形，再经 `TT.geom.fit(FRAME, pre)` 映射。不要按画布安全框直接布内容。
- 样片实测（zoom 1→1.06）：安全框 `115.2,64.8–1804.8,1015.2`；1.06 倍反像 `163.0189,91.6981–1756.981,988.302`；`FRAME {x:-70,y:30,w:2060,h:850}` 的 `fit = 0.773768`。
- 屏幕位置 = 场景位置 × fit × 当前 zoom。所有字号、线宽、间距都先按场景坐标写，再接受这一层统一缩放。

### 字号阶梯

- `RULES.scale` 只给三个倍率：`title / label / note`（样片 `1 / 0.8 / 0.6`）。
- 样片实际字号（写进 `TT.text` 的场景 px）：标题 `66`，标注 `38–52`，注释 `30`。
- 同一样片在屏幕上量到的文字墨迹高度：标题约 `52–55px`，标注约 `34–43px`，注释约 `23–24px`（fit×zoom 之后；抽帧实测约 `23/36/42/53px`）。三个层级必须能同时出现在一帧里。
- 标题是短锚点：开场 12% 内可见、字号 ≥4%H（1080p 约 43px）、字数 ≤8；不要为了“占满宽度”把标题拉长。
- 文字层级只认实际像素高度，不认代码里写了几个字号常量；`RULES.scale` 不读不会报错，但画面层级要看 12 格联系表与人审，不靠代码自述。

### 线宽

- `RULES.stroke = [thin, thick]`（样片 `[2.4, 4.5]`）。
- 细线 `2.4`：刻度、小标注、细节线、短虚线。
- 中线 `(2.4 + 4.5) / 2 = 3.45`：引线、箭头、次级轮廓、注释下划线。
- 粗线 `4.5`：主轮廓、坐标轴、强调线、主体的第一笔。
- 同一张图里的笔迹只使用这三档；不要出现 `3.1 / 3.7 / 5.2` 这种没有规范来源的线宽。平涂纹理里的辅助线不算笔迹线宽。
- 上升流箭头与红叉的 5px 属于强调笔，按强调笔豁免，不计入主笔迹区间。

### 笔速与节拍

- 短笔（一个短笔画、引线、标注线、箭头）：建议 `0.3–1.2s`。样片的短笔主体实测 `0.35–0.9s`；个别主体线到 `1.0–1.15s`，跨屏箭头 `1.25s`。箭头头部按箭杆时长的 `0.215` 倍落笔，不单独算节拍。
- 贯通轮廓是例外：一条连续长线可以到 `1.5–2.0s`。样片实测 `1.5 / 1.6 / 2.0s`；跨屏箭头 `1.25–1.6s`。例外必须是真的“一笔贯通”，不是把多个短笔合并成一段。
- 全片落笔节拍 `4–8` 个。样片实测 6 个。
- 节拍间隔：`0.7–1.2s`，或一次 `≥1.5s` 的长停顿。样片实测间隔 `0.80s`，含一次 `3.40s` 长停顿；第二个 16.5s 范例实测 `0.90s` 间隔、含一次 `6.20s` 长停顿。
- 停顿占比 `15%–45%`。样片实测 30%，第二个范例 40%。
- 节拍看墨迹 bbox 的增长样本，不是单笔 `dur`；不要把“单笔时长”直接当成“节拍间隔”。
- 笔跟当拍主体：主轮廓（场景、主体对象）和**要读者看的强调标注**——圈重点、下划线、箭头、引线——都带笔身；排线、刻度、雨丝、射线这类重复纹理只做短揭示（`dur` 0.1–0.2s），不跟笔。强调标注是叙事的一部分，光有墨没有笔，观众会觉得“这一段没被画出来”。
- 强调标注走 `TT.mark`：线类标注默认只落墨，要带笔时显式传 `penBody: true` 和 `sceneScale`（`fit × zoom`）；填充、底色不带笔。
- 同一时刻只能有一支笔：带笔标注的时段不能与 `heroStrokes` 重叠，多个同向小箭头只给第一支带笔，其余短揭示，避免笔在同一位置连抖几下。`ref-shots/el-nino*.js` 与 `compound-interest.js` 都按这个规则排过时间轴。
- 一个节拍只做一件事：一条轮廓、一个标注组、或一段阶梯；不要在同一节拍里同时开三组新笔画。

### 收尾

- 最后一笔必须在场景结束前 `≥0.6s` 完成；更稳的是最后 12% 完全不落新笔。
- 收尾没有自动评分：末 12% 不落新笔、结束前留约 `0.8s` 静止，末帧是否干净看 12 格联系表末格与人审。
- 三场剖面范例（6.187s / 6.187s / 5.24s）：最后一笔（含带笔强调标注）分别在 5.10 / 4.35 / 3.60s 收完，末 12% 不落新笔，结尾静止约 1.1 / 1.8 / 1.6s。
- 16.5s 图表范例：最后一笔 13.45s 收完（81.5%），末 12%（14.52s 起）不落新笔，结尾静止约 3.0s。
- `TT.pen.track` 在未完成笔画的末端画笔身，笔完后再淡出 80ms；最后 0.6s 内还有笔画，末帧就会带着一支笔。

### 拆场与呼吸

- 长旁白拆成 2–3 场，一场只讲一个阶段；每场独立 `scene.code`，`api.t` 从 0 起，**不要**把全片绝对秒数写进第二场的 `at`。
- 想让「画一波 → 停一拍 → 再补一波」稳定被量到，直接在 `stroke.at` / `prog` 之间留空档（`0.4–0.8s`），**不要**用会冻结笔迹进度的时间重映射。把 `t` 按在某个秒数不动，会让正在进行的笔画和标注一起停在半空：笔身停在原地、标注停在半个字，看起来像卡死，比等它画完更糟。
- 主轮廓与细节分两数组：`heroStrokes` 进带笔身的 `TT.pen.track`，`strokes` 用 `penBody:false` 只落墨，两遍调用共享同一时间轴；`TT.mark` 的强调标注用 `penBody:true` 自带笔，相当于第三路。`ref-shots/` 的范例都按这个结构写，别把所有笔迹塞进同一个带笔身的数组。
- 填充色域改成手绘排线（上下两条边界之间铺若干短笔），每笔都走 `stroke()` 进 ink 回执；整块平涂没有回执，qa 的空墨迹/碰撞检查看不见它。
- 静态镜头（`ZOOM.from === to`）优先：缓慢推镜会让 ink 并集框每帧微涨，画面读起来像持续落笔，呼吸与收尾的观感会一起塌掉。聚焦靠"讲到哪画到哪"，不靠 zoom。

### 纸与笔

- 纸面 / 板面只用 `TT.board.paper(ctx, api)` 或 `TT.board.blackboard(ctx, api)`；不要自己铺整幅底色。
- `board: paper` 是白纸马克笔；`board: blackboard` 自动换绿板 + 粉笔，不需要再手写 `pen: chalk`。
- 笔迹只走 `TT.pen.stroke` / `TT.pen.track`；不要手写笔迹纹理、笔身、笔尖跟随或淡出。`pen` 只允许 `marker` / `pencil`。
- `TT.pen.track(ctx, strokes, t, { sceneScale })`：`sceneScale` 传 code 内施加的场景倍率（fit×zoom；若还有 `scene.camera`，把它的当前倍率也乘进去），笔身才会和纸张同尺度。
- 笔身默认固定 35°；需要跟随时显式传 `rotate: 'follow'`，不要自己算角度。

## 字幕

`caption: tornpaper | perchar | plain`，默认 `tornpaper`（手撕纸背衬，左上胶布取白板墨色 `#343A3B`）。整幅画面在底部落笔、纸背衬会压住内容时，改 `at: "top"` 或 `plain`；同一幕只用一种字幕样式。

## 禁止

- 任何墨迹或文字框越出 `preimage` 可行矩形。qa 对墨迹越界是 should，对文字越界是 must；recipe 有 `ink.insideSafe` 时两者都是 must。
- 同一帧两条文字互压：交叠率 `>12%` 是 must 失败，`5%–12%` 是 should；目标 `<5%`。
- 墨迹与墨迹交叠 `>8%` 是 should；text-ink 不参与碰撞判定，标注可以写在墨迹上。
- 不要把标题横向拉满，也不要为了“填满安全框”而放大标题；镜头会随内容聚焦，宽度不是目标。
- 不要用文字代替笔迹：`fillText` 只进 text 回执，不进 ink 回执；qa 的 ink 几何也不含文字。
- 不要在 code 里手写反像采样或笔身绘制；这两件事分别归 `TT.geom` / `TT.pen`。
- 不与卡片版式混排；同一幕只用一种字幕样式；不把内容写进参数。

## 参数速查

| 项 | 取值 |
|---|---|
| `RULES.safeMargin` | `0.06`（左右 6% / 上下 8%） |
| `RULES.scale` | `title 1 / label 0.8 / note 0.6`（场景 px `66 / 38–52 / 30`） |
| `RULES.stroke` | `[2.4, 4.5]`，中线 `3.45` |
| 笔 / 舞台 | `marker` / `pencil`；`paper`（白纸马克笔）或 `blackboard`（自动粉笔） |
| 字体 | 画面文字 `sans-400`（在 `resources` 声明）；字幕 `captions.font: "JiangChengYuanTi"` |
| 字幕 | `tornpaper`（默认）/ `perchar` / `plain`；胶布取白板墨色 `#343A3B` |
| 节拍 | `4–8` 个落笔节拍；间隔 `0.7–1.2s` 或一次 `≥1.5s` 长停顿；停顿占比 `15%–45%` |
| 收尾 | 最后一笔在结束前 `≥0.6s` 完成，末 12% 不落新笔，结束前留约 `0.8s` 静止 |
