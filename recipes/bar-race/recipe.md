# bar-race · 竞速排行榜

单幕竖屏数据动画：2–18 个实体从起始值增长到结束值，横条长度、实时数值、名次和年份同步变化。固定深色纹理底、斜切渐变标题、彩色横条、底部标尺和右下大年份倒影；不加载国家旗帜、头像或其他实体图片。

本 recipe 是 `params` 类型。内容只写 `scene.params`，不要写 `scene.code`，也不需要补 `scene.resources`；字体由模板固定声明。

## 参数

```json
{
  "title": "2000-2025年重点省区市GDP变化",
  "source": "数据来源：国家统计局、各地统计局 2026",
  "startYear": 2000,
  "endYear": 2025,
  "items": [
    { "label": "广东", "start": 100, "end": 11335.2 },
    { "label": "江苏", "start": 80, "end": 8920.07 }
  ],
  "brand": "@每日读研"
}
```

| 参数 | 规则 |
|---|---|
| `title` | 必填，最多 28 字；单行标题，过长时模板自动缩字号 |
| `source` | 必填，最多 42 字；真实项目必须写真实来源，虚构演示必须明确写“示例”或“虚构” |
| `startYear` / `endYear` | 必填数字；`endYear > startYear` |
| `items` | 必填，2–18 项；每项只含 `label`、`start`、`end` |
| `items[].label` | 2–6 字最佳，建议不超过 8 字；同名实体应避免 |
| `items[].start` / `end` | 非负有限数字，统一以亿元为单位；建议 `end >= start` |
| `brand` | 可选，默认空字符串不显示；右下品牌区最多 16 字 |

不要给实体传 `color`、`icon`、`image` 或 `values`。颜色按 entities 原始顺序从固定 palette 分配，换名次不换色；本版本不是多时间点序列播放器。

## 画面与时间

- 默认画幅 `1080×1920`，一场通常 `8–16s`；数据项越多，越应留足阅读时间。
- `0–0.8s`：斜切标题横幅入场，文字逐字从右侧滑入；条形数值和年份同时开始推进。
- `0.6s` 到结束前 `0.8s`：完整竞速过程；末尾保留最终排名。
- 数值使用 `easeInOutCubic` 从 `start` 到 `end` 插值，条宽使用固定全局终值上限，因此各时刻长度可横向比较。
- 排名每 `0.38s` 计算相邻时间片的起止名次，再用绝对时间插值行位置。没有帧间状态，直接 seek、倒拖和逐帧导出结果一致。
- 名称、条形、实时数值始终属于同一实体；名称在条形左侧，数值在条形右端。
- 年份随数值连续推进并取整，右下显示大年份和翻转倒影；`brand` 只影响可选品牌行。
- 底部 X 轴固定均分四段，以整个榜单最大终值为上限；所有数值与刻度都带“亿”单位。

## 音频与字幕

BGM 固定由 `audio.mood = "tense"` 选择 `紧张脉冲弦乐.mp3`，音量 `0.6`，淡入 `1.2s`、淡出 `2s`。画面本身就是信息主体，`captions.style = "none"`，不要再叠旁白字幕。

## 数据边界

本模板只做一次“起点 → 终点”的视觉竞速，不会凭两个端点还原真实逐年排名。需要真实逐年变化时，应扩展为多时间点数据契约，而不是把插值结果描述成历史事实。示例 storyboard 使用虚构数据，不能作为统计资料引用。

## 交付前

- `tt recipe show bar-race --json` 检查参数契约。
- 编译 skeleton，确认 2–18 项均不越界；至少看开始、中段换位、最终排名三类帧。
- `tt stills` 生成原生 PNG 帧并检查标题、最长实体名、最大数值、年份、倒影、标尺和品牌区。
- `tt qa`、`tt det`；QA 的 `must` 必须为 0，确定性检查两次一致。
- 不导出 MP4，除非用户明确要求。
