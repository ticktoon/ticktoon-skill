# 黑板教学 · code 场写法契约

只写**板面、粉笔、推演节奏**的物理规律：画幅、安全框、字号、线宽、书写节拍、停笔。讲哪一课、写哪些步骤，由 `scene.code` 当场决定；本文件不给课题枚举，也不给例题模板。

## 1 板面与安全区

- 逻辑画幅 1920×1080；`safeMargin = RULES.safeMargin`（本 recipe `0.06`）。
- 板面只用 `TT.board.blackboard(ctx, api)`：深绿板、粉笔槽、板擦与雾面痕迹一次给足；不要再铺第二层底色，也不要换成白板纸。
- 坐标先放在设计框 `FRAME` 内，再用 `TT.geom.preimage` 反推镜头安全框；任何笔迹与文字都不许越出 6% 安全框。
- 镜头可以缓慢推进，但 `preimage` 必须按推镜后的反像区域计算；不要按画布安全框直接布内容。
- 首个书写节拍就要落笔：开场 12% 内必须出现可辨识的板书锚点，不能先空板等旁白。

## 2 粉笔与线宽

- 笔型固定 `chalk`；粉笔线会自动加粗约 `1.14` 倍并带颗粒，不要手写粉笔纹理、笔身或笔尖。
- 笔迹只走 `TT.pen.stroke` / `TT.pen.track`；板书文字走 `TT.text`，圈注与箭头走 `TT.mark`。
- `RULES.stroke = [thin, thick]`（本 recipe `[3, 6]`）：箭头 / 刻度 / 虚线取 3–4；主板、方程与圈注取 5–6。
- 同一块板书只用这两档和其中值；不要出现没有规范来源的线宽。
- 粉笔颜色靠 `chalk` 的默认值；需要强调时用同一粉笔写粗/写重，不要换成彩色马克笔。

## 3 字号阶梯

- `RULES.scale = { title 1, label 0.8, note 0.6 }`；设计字号约 `84 / 45 / 24px`。
- 标题、方程、注释三档必须一眼分层；同一帧至少能同时读出两档。
- 方程与公式用 `num` 角色；正文、步骤说明用 `body`；不要把所有文字压成同一字号。
- 标题是板书锚点，不是海报字：占宽不超过安全框，不要为了“满幅”把公式横向拉满。

## 4 书写节拍

- 单场 `25–35s`，`5–8` 个书写节拍；每个节拍由 `TT.pen.track` 的 `at / dur` 控制。
- 节拍间隔 `1.5–4.5s`；一次节拍只做一件事：一行方程、一个变形、一个圈注，或一组标注。
- 公式推导要按真实书写顺序推进：一般式 → 同除/移项 → 配方 → 开方 → 结论 → 例子；不要先写结论再补过程。
- 例子必须能算到底：代入、判别式、两个根、交点收束，每一步都在板上留下可读的字或线。
- 最后 `12%` 完全不落新笔；最后约 `5s` 停笔，让观众读完板书。
- 淡入淡出与镜头用真实 `T`；只有笔迹进度可以走时间重映射。

## 5 场面组织

- 板面分区稳定：主推导占中部，例子或验算放右侧/下方，注释贴边；不要每步重排整块板。
- 一个节拍里不要同时开三组新笔；先写主体，再补圈注、箭头与下划线。
- 圈注与箭头不得早于它指向的公式；文字标注不得早于对应步骤。
- 整场保持同一块黑板、同一根粉笔、同一镜头方向；拆成多场时每场独立 `scene.code`，`api.t` 从 0 起。

## 6 禁止

- 把讲课内容写成固定模板参数；讲哪一课由 storyboard 的 code 决定。
- 把整段旁白原样抄进 code 当板书；code 只写推导、公式与标注。
- 黑板与卡片混排，或同一幕出现两种字幕样式。
- 用规则几何图形代替粉笔线；用整块平涂代替板书。
- `Math.random` / `Date.now` / 外部 IO；`tt det` 必须两次一致。
- 在同一场景写 `scene.params`；本 recipe 只收 `scene.code`。

## 7 参数速查

| 项 | 取值 |
|---|---|
| `RULES.safeMargin` | `0.06` |
| `RULES.scale` | `title 1 / label 0.8 / note 0.6` |
| `RULES.stroke` | `[3, 6]` |
| 笔型 / 板面 | `chalk` / `blackboard` |
| 单场时长 | `25–35s` |
| 书写节拍 | `5–8` 个，间隔 `1.5–4.5s` |
| 收尾 | 末 `12%` 不落新笔，最后约 `5s` 停笔 |
| 字幕 | `plain`，顶部，`baseSize 44` |
