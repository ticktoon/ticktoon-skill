# shadow-play · 皮影戏

透光幕布上的关节剪影演一段动作，靠姿态、铆钉与垂向操纵杆讲戏；故事由角色骨架与姿态承载。

## 何时用

- 民间故事、寓言、历史小段，动作与姿态比台词重要。
- 需要“戏台”质感：暖黄幕布、黑色剪影、关节可活动。
- 角色可以用几个关节骨架表达，而不是写实插画。

## 何时不用

- 需要真实镜头 → `footage-cut`。
- 需要图表、步骤或现代信息版式 → 其他 recipe。
- 人物必须写实或有表情细节 → `illustrated-story`。

## 内容怎么写

- 每场一个 `scene.shadow`，`rect` 固定 `[0,0,1,1]` 满幅戏台，不要加卡片版位。
- `characters[]` 只写骨架与姿态；`title` / `subtitle` / `plaques` 只写文本，不写人物身份枚举。
- 不要在 `characters[]` 之外再画人物；同一场只用一种幕布底色。
- 字幕固定 `none`：画面文字就是 `title`。
- 动作靠姿态切换与操纵杆倾角，不靠逐帧随机抖动。

## 视觉与数值依据

- 调色板固定在 block 内：深棕夜底（`#191008`）、暖黄剪影（`#F2DCA8`）、琥珀强调（`#E8A33D`）；recipe 不再声明颜色。
- `rules.safeMargin: 0.06`；`rules.scale: title 1 / label 0.8 / note 0.6`。
- `rules.stroke: [3, 6]`：关节轮廓与操纵杆用粗档，铆钉与细线用细档。
- `captions.style: "none"`；`audio.mood: "tense"`，音量 0.11，淡入 1.4s / 淡出 2.2s。
- `signature` 是「透光关节剪影」：首帧就要有剪影与名牌凭据，`verify.t = 1.2`。

## demo

《渡口》两场：更鼓敲过三下，有人提灯往渡口走 / 孩子在门口招手，一只小兽跟在后面。
两场都用 `scene.shadow` 的骨架与姿态，台词压成标题与名牌，不叠字幕。
