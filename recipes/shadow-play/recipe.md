# shadow-play · 皮影戏

暖光透过幕布，侧面镂空的人物、建筑与器物在灯影里演戏。统一的是纸、皮、光与关节的语言，不是固定舞台构图；每一场的人物、道具、山水和建筑都根据剧情写在 `scene.code` 里。

选中本 recipe 后，以这份文档为创作纲要。`ref-shots/` 是不同整幕的完整写法，不是可枚举的剧情模板，也不会自动注入其他场景。

## 内容怎么写

- 每场只写 `scene.code`；`narration` 决定这一场演什么。先找本场动作与视觉焦点，再决定人物数量、空间和道具，不从固定人物列表出发。
- 一场只承担一个戏剧情拍：点灯、问卜、奏乐、登城、渡水等。换地点、换主要人物关系或换说话角色时，优先拆成新场。
- `narration` 只写角色实际说的话，不写“某某说”、舞台提示或角色名；角色名由本场 code 的 `speaker` 负责显示。
- 不要为“展示皮影”而添加标题、名牌或旁白复述。画面先演故事；确有对白时才画底部对白条。
- 单个 cue 尽量是一句短对白，建议不超过 24 个汉字。长段讲话拆成多个 cue 或多场，避免底部文字缩成小字。
- 常规故事写 6–8 场、总时长约 45–70 秒；不要用六七句短对白凑成二十多秒的“皮影快闪”。故事容量不够时补足动作、停顿和对白，不靠加速切换制造推进。
- 有对白的场次由 recipe 固定为开场留白 1.2 秒、结尾停留 2.2 秒，且最短 6.5 秒；通常应处在 6–10 秒。静默场 `duration` 通常写 6–10 秒，不得再用 2–3 秒静默场只让画面闪一下。

## 画面怎么写

### 幕布与光影

- 幕布背景只调用一次 `TT.board.stage(ctx, { W, H }, { seed })`。宣纸、织纹、顶部暖光都由它完成，**不得再铺第二层底色**。
- 所有场景内容画完后，调用一次 `TT.board.stageFrame(ctx, { W, H })`。它只画四角木框，起装饰作用,其他区域完全透明；山体、建筑和人物即使铺满幕布，也不会盖住框角。
- 剧情需要的局部光照可以画在幕布之上：油灯用径向渐变，火光用半透明暖色轮廓，裂缝与声波用受控的亮线。它们是“戏”，不是新幕布。
- 常用色：深轮廓 `#32170f`、朱红皮片 `#9e3d2c`、青绿皮片 `#315c56`、透光金 `#d8a457`、孔洞亮纸 `#f1d59a`、远景褐 `#9a7048`。同场主色控制在 2–3 种。
- 灯影用同一主体轮廓的简化形、轻偏移与低透明度，不用实时模糊滤镜堆叠。火光只能小幅、连续变化，例如 `Math.sin(api.t * 5) * 0.03`，不能每帧随机闪烁。

### 侧面人物与镂空

- 人物以**侧面轮廓**辨认：额、鼻、唇、下巴组成连续侧脸，头饰、衣摆和手足用独立皮片连接。不要画正面大眼卡通脸。
- 关节处保留深色外圈与金色铆钉；操纵杆从肩、腕或背部接向幕布下沿，细而清楚，不抢主体。
- 镂空用菱形、半月、弧线和成组细缝。孔洞在皮片内部填孔洞亮纸色，或用较亮细线描出；不要用 `destination-out` 把幕布一起擦掉。
- 人物动作以关节旋转、整体滑入、衣摆轻摆为主。每拍只动一两个部位；不要用高频抖动假装“手工感”。

### 场景与道具

- 每场按剧情重新组织空间。可以是油灯特写、龟甲占卜、编钟架、长城烽火、卷轴水城、街巷灯笼，也可以是故事需要的其他构图。
- 推荐绘制顺序：`TT.board.stage` 幕布背景与整体暗角 → 低对比远景 → 建筑与独立器物 → 人物与操纵杆 → 前景遮挡 → 对白条 → `TT.board.stageFrame` 四角木框。
- 建筑用层叠屋檐、斗拱、窗格和城墙缺口形成皮影语言；山水用剪影层与稀疏透光线；水纹、声波、裂纹都是本场叙事的一部分，不是通用装饰。
- 道具要有清楚的轮廓和比例。油灯、编钟、舟桥这类叙事焦点可以占画面主体，不必永远把人物放在右侧、标题放在左侧。
- 镜头默认静止，幕布木框始终固定。不要把手绘白板那套逐笔落墨搬过来：皮片是预先雕好的，靠入场、转关节和光影变化演戏。

### 出场与节拍

- 开场 0–0.8 秒建立主轮廓；人物从侧边滑入，器物可淡入、落下或被灯光逐渐照亮。主轮廓建立后继续保留观看空档，不能一完成入场就切场。
- 用 `api.t` 与固定序号计算运动；禁止 `Math.random` / `Date.now`。同一个输入必须逐帧可复现。
- 对白出现前给观众一个看清人物与动作的空档；对白持续期间只做低幅呼吸、衣摆或火光运动。
- 对白结束后至少保留 2.2 秒稳定表演；最后 12% 不再引入新人物或新道具。场间切换只在边界前一场声明固定 `transition` 预设，不在场景末尾自行淡出。

## 两段式角色对白条

`captions.style` 固定为 `none`，公共字幕不会再画一层。凡有对白的场景，由该场 `scene.code` 按同一规范绘制：

- 位置：底部装饰带，参考矩形 `x = W * 0.10`、`y = H * 0.835`、`w = W * 0.80`、`h = 104`；必须在 `RULES.safeMargin` 内。
- 两段结构：左侧朱红角色牌，宽 `190–230px`，金色细边，角色名用 `sans-900`；右侧浅色讲话区，讲话内容用 `sans-400`，深棕色。
- 基准字号：角色名 `72 * RULES.scale.speaker`，讲话内容 `72 * RULES.scale.dialogue`；内容必要时传 `maxWidth`，不要把角色名拼进讲话字符串。
- 内容读取当前 `api.cues` 的 `cue.text`，只在 `cue.start <= api.t < cue.end` 时显示。不要再次读取公共 captions，也不要把整段 narration 抄进 code。
- 一个场景优先只有一个说话角色；连续多人对话拆场。确需同场轮换时，用本地 `speakers[]` 按 cue 顺序取角色名，不修改 cue 数据。
- ref-shot 文件头没有 `narration`，所以 lab 预览要用演示 cue 兜底；正式 storyboard 有真实 cues 时自动走真实内容：

```js
const cues = api.cues.length
  ? api.cues
  : [{ text: '灯里也有影子在跑！', start: 0.5, end: api.d - 0.3 }];
const cue = cues.find((c) => api.t >= c.start && api.t < c.end);
const speaker = '小影';
if (cue) {
  // 在这里画完整底部对白条：speaker 一段，cue.text 一段。
}
```

完整写法见 `ref-shots/lantern-street-dialogue.js`。它是一整幕街巷戏，不是孤立字幕组件；复用时连舞台、人物、 cue 读取和对白条一起理解。

## 禁止

- `scene.params`、固定人物/姿态/道具枚举、所有场次共用一张构图。
- 公共字幕与自绘对白同时出现；把角色名读进 TTS；把角色名和讲话内容拼成一段普通字幕。
- 正面写实人物、厚重照片质感、现代 UI 卡片、与剧情无关的标题牌匾。
- 用高频随机抖动表现灯影；擦掉幕布的真镂空；墨迹、文字或主体越出安全框。

## 参数速查

| 项 | 取值 |
|---|---|
| 模式 | `code`，每场独立 `scene.code` |
| 舞台 | 背景 `TT.board.stage`，固定 `seed`；末尾前景 `TT.board.stageFrame`，只画四角 |
| 安全边距 | `RULES.safeMargin = 0.055` |
| 线宽 | `RULES.stroke = [2.5, 7]`，纹样/操纵杆用细档，主轮廓用粗档 |
| 字号基准 | `72 × RULES.scale`：speaker 0.62 / dialogue 0.58 |
| 字体 | 角色名 `sans-900`，讲话内容 `sans-400`，均在本场 `resources` 声明 |
| 字幕 | `captions.style: "none"`；对白由场景绘制 |
| 节拍 | 对白场 lead-in 1.2s / hold 2.2s / 最短 6.5s；静默场通常 6–10s |
| 音频 | `mood: tense`，音量 0.11，淡入 1.4s / 淡出 2.2s |

## 整幕示例

`ref-shots/` 提供五种不同组织方式：街巷灯笼与双人对白、油灯龟甲与发光裂纹、编钟架与声波、长城山体与烽火、卷轴水城与拱桥小船。它们只展示写法与视觉物理规律；新故事必须重新决定场景内容，不要照抄人物身份和对白。
