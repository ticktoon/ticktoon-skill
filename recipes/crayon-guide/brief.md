# crayon-guide · 蜡笔图解

暖米纸、斜纹蜡笔填充、手写标签与引线、紫描边气泡、三根蜡笔柱步骤卡——一套「手账 / 绘本」视觉。
recipe 只规定这套视觉的固定项，题材与叙事由 storyboard 自由组织。

## 视觉

- `scene.crayon` 必须是本场唯一元素，且显式 `rect: [0, 0, 1, 1]`；纸底要铺满画幅。
- 固定结构：红圈角标 → 标题/副标题 → 对话气泡 → 食材（或材料）四格 → 三根蜡笔柱步骤卡 → 合计与右下角手写注。
- `steps` 与 `times` 按同一顺序一一对应，最多 3 组；`times` 是分钟数，柱高与「合计」都由它算。
- 字幕固定 `handnote`；demo 用 `at: "auto"` 避开场景中央的主体带（block 内建 `captionAvoid`）。
- 蜡笔斜纹与颗粒只由序号哈希算出，同一帧必须给出同一张纸；禁止在 storyboard 或代码里引入随机。

## rules 数值依据（静帧复核）

- `safeMargin: 0.06` —— 四角角标、标题、右下角注在静帧里都落在 6% 边距内；再小会让红圈角标贴边。
- `scale: title 1.0 / label 0.8 / note 0.6` —— 标题 → 步骤/材料标签 → 右下角小注的三档层级。
- `stroke: [2.0, 4.6]` —— 主体轮廓与柱边 3.2–4.6，细描边/引线 2.0–2.8；7px 下划线属于强调笔，不算主笔迹。
- `caption: handnote`（fixed）—— 这套视觉只允许手写批注体，换字幕样式会破坏手账感。
- `forbid`：不与卡片块混排；不缩成卡片；steps/times 不配对时不要硬塞；字幕不压步骤卡与右下角注。

## demo

`窗台种葱`：四样材料、三步（铺土插种 / 薄土浇透 / 窗台晒太阳）、每步用时 2/3/1 分钟，
旁白补上「头三天别暴晒、一周发芽」的时间跨度。约 15 秒，画面在第 9 秒左右停笔收尾。
