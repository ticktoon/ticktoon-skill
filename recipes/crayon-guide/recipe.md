# crayon-guide · 蜡笔图解

暖米纸上，用带颗粒的蜡笔人物、器物、对比柱和手写标注讲故事。统一的是蜡笔触感与绘本气质，不是固定的材料区、步骤数或卡片版式；每场构图根据 `narration` 写在 `scene.code` 里。

选中本 recipe 后，以这份文档为创作纲要。`ref-shots/` 是完整整幕写法，不是剧情枚举，也不会自动成为其他场景的共享运行时。

## 内容怎么写

- 每场只写 `scene.code`。先判断这一幕最适合用人物表演、左右对照、数量对比、分层结构还是器物特写，再安排画面。
- 一场表达一个核心关系或结论。例如“不同团队的塔高不同”“安全感支撑共同目标”“大人与孩子形成对照”“两种提问带来不同反应”。
- 画面标签写解释所需的最短文字，不照抄整段 narration；数据、人名和关系必须来自内容，不编造参考图中的研究结论。
- 长内容拆成多场。人物、问题或结论变化时重新组织构图，不要把所有信息塞进一张复杂海报。
- 公共字幕固定 `handnote`，由 `captions` 读取 cues；场景内标签与公共字幕不能重复同一句话。

## 画面怎么写

### 纸张与蜡笔物理规律

- 舞台只调用一次 `TT.board.crayon(ctx, api, { seed })`，暖米纸、浅斜纹和毛糙纸边由它给足；不得再铺第二层纸底。
- 蜡笔色块由三层组成：很淡的底色、方向一致的斜向排线、少量固定颗粒。主轮廓再叠一遍较细、较淡的偏移线形成蜡质毛边。
- 排线不是每帧重新随机。用整数序号哈希决定偏移、宽度、颗粒和透明度；`api.t` 只负责生长、淡入和动作。
- 人物与器物不要写成完美矢量图标：圆可略扁，直线可轻微弯曲，填色可以越过一点点轮廓，但文字始终清楚。
- 常用色：墨 `#3a352d`、次级 `#6c6255`、红 `#c9605b`、橙 `#d97a52`、紫 `#8f7bc2`、绿 `#7fae8c`、蓝 `#5f87a8`、赭黄 `#d9a74f`。同场主色 3–5 种即可。

### 人物与器物

- 人物用圆头、简单头发、豆点眼睛、短弧线表情和有余量的手脚比例。年龄、身份和情绪靠体型、发型、服装、姿态表达，不靠文字硬贴标签。
- 大人与孩子的身高差、对话者的前倾与后仰、举手与叉腰等姿态是内容；不同场次不要只换衣服颜色。
- 衣服和头发用蜡笔排线，皮肤用很淡的暖色。五官线条比外轮廓细，不画写实阴影。
- 材料与器物根据剧情实时画：面条、胶带、棉花糖、杯碗、植物或任何本场需要的对象。器物下方可配短标签，但不要恢复固定四格材料区。

### 图解与标注

- 数量对比可以用高低明显的蜡笔柱、实物数量或人物组。柱内可加交叉支撑、颗粒与顶部实物；数值用 `sans-900`，标签用手写体。
- 分层结构用不规则梯形、堆叠色块、顶部星形或箭头表达。每一层只放一个短标签，引线轻、短、不穿过人物。
- 左右对照用一条手绘竖线或明显留白分区，不使用现代 UI 卡片。两边的人物姿态和情绪也应不同，而不只是文字不同。
- 对话框、角标和说明框都由不规则蜡笔线构成。框内仍是大片纸色，不铺厚重底色。
- 所有文字走 `TT.text`，保证文字回执。标题和正文用 `ZTZiYouTi`，关键数字可用 `sans-900`；整行只做轻微固定旋转，不逐字随机跳动。

### 构图与字幕带

- 画面满幅展开，主表演区约为 `y = 100…0.80H`。底部 `0.84H…H` 默认留给公共 `handnote` 字幕，不安排人物、地线、来源小注或场景结论。
- 安全边距使用 `RULES.safeMargin`；角标可以靠近左上，但不能贴出画面。默认静态镜头，不用推镜制造纸纹漂移。
- 推荐层级：纸张 → 淡远景/分区线 → 主体与器物 → 人物 → 标注与强调线。字幕最后由公共 captions 绘制。
- 参考图里的底部句子属于字幕语义时，正式场景交给 `narration`，不要在 code 里再写一遍。

## 出场与节拍

- 开场 0–1 秒先建立角标、主要人物或核心器物；复杂场景按“主体 → 数量/结构 → 标签 → 结论强调”分拍出现。
- 柱高从地面生长，人物可轻微放大入场，标注线与对话框用外部 `progress` 逐渐画出。不要每帧抖动整个人物。
- 动作幅度小而持续：呼吸、身体前倾、手臂抬起、问号轻弹即可。不要冻结正在生长的线条来制造停顿。
- 最后 12% 不再引入新主体，保留稳定画面给字幕读完。整体淡入淡出可用 `TT.env.fade`。
- 禁止 `Math.random` / `Date.now`；所有纹理、人物细节与装饰位置都必须可复现。

## 参数速查

| 项 | 取值 |
|---|---|
| 模式 | `code`，每场独立 `scene.code` |
| 舞台 | `TT.board.crayon`，固定 `seed` |
| 安全边距 | `RULES.safeMargin = 0.055` |
| 线宽 | `RULES.stroke = [2, 4.6]`，五官/引线用细档，主轮廓用粗档 |
| 字号 | 标题约 `76 × RULES.scale.title`；标签基准 `48 × RULES.scale.label`；小注基准 `36 × RULES.scale.note` |
| 字体 | 手写文字 `ZTZiYouTi`，数字 `sans-900`，在本场 `resources` 声明 |
| 字幕 | `handnote`，`top: 0.84`，`maxWidth: 0.56` |
| 音频 | `mood: soft`，音量 0.08，淡入 1.5s / 淡出 2.2s |

## 整幕示例

`ref-shots/` 提供四种不同组织方式：团队与塔高对比、三层目标塔与说明框、人物关系与大小对照、左右提问与情绪反应。它们只复用蜡笔物理规律和构图方法；新故事必须重新决定人物、器物、标签与数据，不要照抄参考图内容。
