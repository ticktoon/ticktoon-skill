# 插画剪报 · code 场写法契约

只写**拼贴的物理规律**：纸、透视、撕边、排线、字幕带分区。画什么故事由 LLM 在 `scene.code` 里实时决定，不给题材枚举、不给图元库。

## 1 载体与分区

- code 场只写 `scene.code`；舞台只用 `TT.board.cream(ctx, api, { seed })`：米色纸、短纤维、浅斑、四边压深由它一次给足，**不许再铺第二层底色**。
- 笔迹走 `TT.pen.stroke` / `TT.pen.track`，文字走 `TT.text`，标注走 `TT.mark`。
- 字幕固定一层 `captions.collage`，`at: "bottom"`。**主体集中在画面上半（y ≤ 700），字幕带留在下半**：场景不向字幕层提交避障框，字幕不会自动避让，只能靠画面分区解决。
- 静态镜头优先（不推镜）：缓慢推镜会让 ink 并集框每帧微涨，画面读起来像持续落笔；没有自动评分兜底，观感看 12 格联系表与人审。

## 2 窗台透视

- 两条**不平行**的斜线交出台面厚度：上沿与下沿向右逐渐收窄，收窄量约 30–40px。
- 台面用短排线带出进深，间距按序号固定，不用渐变填充。
- 透视线的终点不要越过 `safeMargin`（默认 0.06 → 右边界约 1805px @1920）；越界不会自动判 must，用 `tt probe` 回算墨迹框，再看 12 格联系表。

## 3 电线与弧线

- 电线用三次曲线，垂度由中间两个控制点给出；**不要随帧摆动**（`det` 两次要一致）。
- 两根线用不同灰度和线宽，形成前后层次；主线粗、副线细且略透明。
- 展翅、侧影这类动作轮廓用对称的两道弧线，末端出锋，不画五官细节——拼贴风靠形状不靠细节。

## 4 纸片与色域

- 纸片边缘是**手绘撕边**：四边各拆成 12 段短折线，段端点用序号的正弦函数抖动，转角不封死。
- 纸片内部与大面积色域一律用**斜向排线织出来**，不用整块平涂：每笔都进 ink 回执，qa 才抓得到越界与碰撞。
- 排线的末端也要收在安全框内；算 x 上限时记得加上斜线的水平偏移。

## 5 节拍

- 长旁白拆 2–3 场，每场独立 `scene.code`，`api.t` 从 0 起。
- 呼吸用一行时间重映射，`t` 只喂笔迹进度，淡入淡出与镜头用真实 `T`：
  ```js
  const T = api.t;
  const t = T < 1.5 ? T : (T < 2.6 ? 1.5 : 1.5 + (T - 2.6) * 2.6);
  ```
- 开场要在 12% 窗口内给一个可辨识锚点：字号 ≥4%H（1080p 约 43px）、短句 ≤8 字。小字角标不能当唯一开场文字。
- 最后一笔在倒数第二个采样点前落完，末 12% 不落新笔。

## 6 禁止

- 题材枚举、预设图形库、把整段旁白抄进 code 当画面文字。
- 两种字幕样式叠在同一幕；标题大字与字幕说同一句话。
- 整块平涂代替纸片；第二层底色；墨迹/文字越出安全框。
- `Math.random` / `Date.now` / 任何外部 API。

## 7 参数速查

| 项 | 取值 |
|---|---|
| `RULES.stroke` | `[2, 4]` |
| `RULES.safeMargin` | `0.06` |
| 舞台 | `cream`，`seed` 固定 |
| 主色 | 墨 `#2b3a42` / 蓝 `#3f6f8f` / 暖 `#c96a4d` / 灰 `#8b8578` |
| 字幕 | `collage` + `at: bottom`，`maxWidth ≈ 0.62` |
